Understanding () in Java Functions

The parentheses () are used to define function parameters (inputs).
Empty ()	Function takes no parameters (no input)
(String email)	Function takes one parameter named email of type String
(String email, int count)	Function takes multiple parameters separated by commas

sendEmail();                                    // No arguments
sendEmail("john@example.com");                 // One argument
sendEmail("john@example.com", "Hello Java");   // Two arguments
